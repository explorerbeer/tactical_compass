<p><strong>CHANGELOG</strong></p>

<p><strong>v5</strong></p>

<p>New:</p>
<ul>
<li>Compass style (S.T.A.L.K.E.R. 2 / classic) is now switchable in MCM Ч no separate install option.</li>
<li>Marker icons (custom / vanilla) are now switchable in MCM Ч no separate install option.</li>
<li>Compass scale slider, with ultrawide monitor support.</li>
<li>Drop shadows on the compass and markers, so they stay readable against a bright sky. The marker shadow can be turned off in MCM.</li>
</ul>

<p>Fixed:</p>
<ul>
<li>The compass and marker icons rendered incorrectly on the R1 renderer (DX8 / DX9). All textures are now power-of-two.</li>
<li>"Always display" for a marker category also forced the distance readout on, ignoring that category's own checkbox.</li>
<li>Markers were positioned for the S2 compass width even on the classic style, and the classic compass itself sat a few pixels off centre.</li>
<li>Distance numbers wrapped onto two lines at 100 and above.</li>
<li>Markers could break or disappear after changing level.</li>
<li>Marker UI elements piled up over a long session instead of being released.</li>
<li>Fixed a bug where the addon overwrote a shared engine value used by other scripts.</li>
</ul>

<p>Performance:</p>
<ul>
<li>The compass and markers no longer query MCM or allocate memory every frame.</li>
<li>Nothing is computed while the HUD is hidden (inventory, PDA, hidden HUD).</li>
<li>Level load: the map spot scan is faster on first visit and skipped entirely on return.</li>
</ul>

<p>Compatibility:</p>
<ul>
<li>The addon no longer replaces <em>axr_main.script</em> and <em>bind_stalker.script</em>. It will not conflict with other mods touching those files, and it survives Anomaly updates.</li>
</ul>

<p><strong>IMPORTANT:</strong> delete the previous version completely before installing this one. Script files were renamed; leftovers from the old version will run alongside the new ones and you will get two compasses at once.</p>

<p>A compass strip in the spirit of S.T.A.L.K.E.R. 2, PUBG and Squad, with a marker
system that puts your PDA map spots right on it Ч quests, stashes, level transitions,
unique NPCs and more. Fully configurable through MCM.</p>

<p><a href="https://www.youtube.com/watch?v=boGvng0kotI" target="_blank" rel="noopener">Compass demonstration</a><br />
<a href="https://github.com/explorerbeer/tactical_compass" target="_blank" rel="noopener">Russian description and source code on GitHub</a></p>

<p><strong>FEATURES</strong></p>

<ul>
<li><strong>Two compass styles</strong> Ч S.T.A.L.K.E.R. 2 and the classic one, switchable in MCM at any time.</li>
<li><strong>Two marker icon sets</strong> Ч custom icons by Rier, or vanilla PDA icons that match your own icon addons.</li>
<li><strong>Nine marker categories</strong>: quest targets, unique NPCs, sleeping spots, stashes, level transitions, NPC squads, corpses, campfires and water pumps.</li>
<li><strong>Per-category settings</strong> Ч enable or disable each type, set its display range, or make it always visible regardless of distance.</li>
<li><strong>Distance to target</strong>, shown when you look straight at a marker.</li>
<li><strong>Elevation arrows</strong> Ч a marker tells you whether the target is above or below you.</li>
<li><strong>Distance fade</strong> Ч markers fade out smoothly instead of popping in and out.</li>
<li><strong>Drop shadows</strong> so the compass and markers stay readable against a bright sky.</li>
<li><strong>Scale slider</strong> Ч resize the whole compass, including support for ultrawide monitors.</li>
<li><strong>Hotkey toggle</strong> (M by default) to hide the compass and markers.</li>
</ul>

<p><strong>INSTALLATION</strong></p>

<p>Install MCM, then install this addon. Mod Organizer 2 is strongly recommended.</p>

<p><strong>UPDATING FROM AN OLDER VERSION Ч PLEASE READ</strong></p>

<p>Delete the previous version completely before installing this one. The script files
were renamed in this release, and leftovers from the old version will keep running
alongside the new ones Ч you will end up with two compasses on screen at once.
In MO2 this means removing the old mod entry, not just overwriting it.</p>

<p><strong>CONFIGURATION</strong></p>

<p>Everything is in MCM under <em>Tactical Compass</em>:</p>
<ul>
<li><strong>Main settings</strong> Ч compass style, position on screen (top or bottom), scale.</li>
<li><strong>Markers</strong> Ч icon set, drop shadow, and the four options for each of the nine marker categories.</li>
<li><strong>Key binding</strong> Ч the toggle key.</li>
</ul>

<p><strong>ULTRAWIDE MONITORS</strong></p>

<p>The engine stretches the interface horizontally on anything wider than 16:9, which
makes the compass too wide. Set <em>Compass scale</em> to about <strong>0.75</strong>
for 21:9 and <strong>0.50</strong> for 32:9. On regular monitors the slider simply
resizes the compass.</p>

<p><strong>KNOWN ISSUES</strong></p>

<p>The minimap reappears after changing screen resolution. This is an engine bug Ч
it reproduces with the addon disabled.</p>
